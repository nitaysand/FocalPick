# איך תורמים

תודה שרצית לעזור. אפשר לתרום גם בלי לכתוב קוד, ולרוב זה מה שהכי עוזר:

## תרומות ידע (בלי קוד)

| מה | איפה |
|---|---|
| מגבלות של שכבות חינמיות, מודלים שמבינים תמונות, הערות על ספקים | הקובץ `providers.json`. זה קובץ טקסט פשוט, ואפשר לערוך אותו ישירות באתר |
| ניסוחים בעברית שלא נשמעים טבעיים | פתיחת "תיקון ניסוח", או Pull Request |
| קבצי טעם לדוגמה (`taste.txt`) לסוגי צילום שונים | תיקיית `examples/` |
| דיווח על באג | "דיווח על באג" (מצרפים את `run_log.txt` ומוחקים ממנו מפתחות) |
| רעיון לתכונה | "בקשת תכונה" |
| תרגום לשפה אחרת | פתיחת נושא לפני שמתחילים, כדי לתאם |

## תרומות קוד

1. פתחו קודם נושא (Issue) לתיאום, כדי לוודא שהכיוון מתאים.
2. הקוד משתמש בספרייה הסטנדרטית של פייתון וב-Pillow ו-NumPy בלבד (`rawpy` אופציונלי). אין להוסיף תלות חדשה בלי לתאם.
3. הכלים חייבים לעבוד ב-Windows, כולל שמות תיקיות בעברית ובלי rawpy.
4. הודעות למשתמש בעברית טבעית וברורה, בלי תרגום מילולי. אל תשלבו אנגלית באמצע משפט בעברית בתוויות בממשק.
5. אל תכניסו מפתחות, נתיבים אישיים או תמונות פרטיות לקוד, ללוגים או לנושאים.
6. הריצו את הכלים על תיקייה קטנה לפני שליחה, ובדקו גם במראה בהיר וגם בכהה אם שיניתם את הממשק.

## תנאי תרומה

על מנת שאוכל להמשיך ולהפיץ את הכלי בצורה חוקית, כל תרומה כפופה לתנאים הבאים (הנוסח האנגלי הוא המחייב, והסיכום בעברית נועד להקל). בשליחת Pull Request אתם מצהירים שקראתם והסכמתם.

**בקצרה:** התרומה שלכם נשארת שלכם. אתם נותנים לי רישיון להשתמש בה בפרויקט, כולל לשנות את רישיון הפרויקט בעתיד. אתם מצהירים שיש לכם זכות לתרום אותה. אין חובה למזג תרומה, והשם וכתובת האימייל שבהיסטוריית הגיט פומביים.
